# Samarth Goel - Portfolio Website

A modern, responsive portfolio website built with vanilla HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View Live Site](https://portfolio-eta-umber-56.vercel.app)

## ✨ Features

- **Modern Dark Theme** - Professional developer-centric aesthetic
- **Fully Responsive** - Works on mobile, tablet, and desktop
- **Smooth Animations** - Scroll-triggered fade-ins and hover effects
- **Accessibility** - Keyboard navigation and focus states
- **Fast Loading** - Single HTML file, no build step required

## 🛠️ Deployment

### Vercel (Recommended)

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "Add New Project"
4. Import your GitHub repository
5. Deploy (no configuration needed)

### GitHub Pages

1. Go to repo Settings → Pages
2. Select "Deploy from a branch"
3. Choose `main` branch and `/ (root)`
4. Save

## 📝 Customization

- **Resume**: Add your `Samarth_Goel_Resume.pdf` file to the root folder
- **Project Links**: Update GitHub links in `index.html` to point to specific repos
- **Content**: Edit the HTML directly to update experience, projects, etc.
